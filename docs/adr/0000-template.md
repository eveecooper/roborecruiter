# ADR 0000: Template

> Copy this file to `NNNN-short-title.md`, incrementing the number. One ADR per significant
> decision. An ADR outranks the planning documents on the single decision it records.

- **Status:** proposed | accepted | superseded by [ADR NNNN](NNNN-short-title.md)
- **Date:** YYYY-MM-DD
- **Deciders:**

## Context

What forced the decision. The constraint, the measurement, or the failure that made the previous
approach untenable. If an investigation brief produced this, link it.

## Decision

What was decided, in one or two sentences, stated in the present tense.

## Consequences

What this makes easy, what it makes hard, and what it forecloses. Include the cost that was
accepted, not only the benefit.

## Alternatives considered

What else was on the table and why it lost. An alternative rejected for a reason that later stops
holding is the most useful thing in this file.

## Evidence

Measurements, source documentation, or fixtures the decision rests on. If the decision rests on an
assumption rather than evidence, say so here and name what would test it.
